# Immunis

Prototype of a vaccination recommendation engine for the Moroccan vaccination schedule.

## Current status

Early prototype.

Currently implemented:

- TypeScript engine foundation
- DTP catch-up policy in YAML
- Zod validation for DTP policy
- DTP/Penta dose validity checking
- Valid DTP-containing dose counting
- DTP catch-up rule selection

Not yet implemented:

- Protocol scheduling with actual dates
- Full catch-up visit plan
- Other vaccines
- Spacing rules
- PCV transition rules
- API
- Database
- UI
